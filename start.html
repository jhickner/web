web

Headless Chrome, visible in your terminal.

Chrome draws this page, the frame arrives as a PNG, and your terminal paints it with kitty graphics — and keys and clicks go back the other way.

chrome ─► png ─► kitty ─► terminal
   ▲                             │
   └───── keys, mouse ───────────┘

Quick start

  1. ? Help menu. Every key, drawn over the page. Any key puts it away.
  2. f Labelled links, for keyboard-only navigation. Type a label to follow it — try it on the repo. F opens one in a new tab, esc puts the labels away.
  3. [ ] Resize the browser window within your terminal. It grows and shrinks from both edges.
  4. w W Change the reported browser size — the zoom level. The page is told it has a different width and reflows to it. alt+0 puts both back.
  5. ^Lo The location bar. A phrase with no dot in it opens the bookmark it names, or becomes a search. O opens a blank one in a new tab.
  6. ^X :^X The JavaScript console. It runs in the page — try document.title. The vi layer takes : for the location bar, so the console is ^X alone.

These are the default keys. vim = yes in web.conf turns on the vi layer: j k move, gg G top and bottom, / then n finds, H L go back and forward. The vi layer, vim = yes in web.conf. j k d u move, gg G top and bottom, / then n finds, H L go back and forward, ZZ quits. It sits under web.conf, so any key the file names keeps what the file gave it.

A note on optimization

The picture downscales while moving or scrolling, then resolves when stopped. You can disable this by pressing s or by setting motion-scale = 1 in web.conf.

More than reading

logins
web --login opens a normal Chrome window on this profile. Sign in to whatever you need there, and every window keeps the session.
tabs
^T ^W open and close, ^N ^B move between them, alt+g draws every one at once in a grid.
finding
alt+b the bookmarks, alt+d to add this page. Type words in any order; each one narrows the list.
scripting
Piped JavaScript runs a line at a time, the page still on screen: echo 'document.title' | web example.com
driving
web --mcp gives an agent this window — your logins, your tabs — and you watch it work. web --exec 'npx playwright test' runs a suite in it.
recording
alt+r writes what you do to the page out as a Playwright spec, rewritten after every step.
screenshots
web --screenshot shot.png example.com, and - for stdout.

Customization

~/.config/web/web.conf

vim       = yes   # the whole vi layer
zoom      = 1.5
cols      = 100
search    = https://duckduckgo.com/?q=%s
f5        = reload

Written with the defaults on first run. Every setting is also a command-line option, and any key can be rebound to any action by name.
